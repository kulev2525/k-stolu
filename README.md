# К столу

[![Static checks](https://github.com/kulev2525/k-stolu/actions/workflows/quality.yml/badge.svg)](https://github.com/kulev2525/k-stolu/actions/workflows/quality.yml)

Веб-помощник для одновременного приготовления 2–3 блюд. Общий план должен учитывать занятость человека, конфорок, духовки и посуды и помогать подать блюда примерно одновременно.

## Состояние проекта

Подготовлены требования и архитектура. Этот репозиторий содержит основу для совместной разработки; приложение, каталог рецептов и планировщик ещё не реализованы. Инструкции запуска приложения появятся вместе с кодом. Целевой срок MVP — 14 декабря 2026 года.

## Технологии

По архитектуре от 29 октября 2026 года:

- интерфейс: React, TypeScript, Vite;
- сервер: Python 3.12, FastAPI, SQLAlchemy;
- хранение: SQLite; рецепты в YAML;
- проверки: Ruff, ESLint, Prettier; далее pytest, Hypothesis, Vitest и Playwright.

## Структура

```text
backend/           Будущий сервер и независимое ядро планировщика
frontend/          Будущий интерфейс
recipes/           Будущий каталог рецептов
docs/              Требования, архитектура и проверки качества
.github/           Автоматические проверки и шаблоны задач
```

## Работа с проектом

1. Прочитайте [требования](docs/requirements.md) и [архитектуру](docs/architecture.md).
2. Создайте задачу с ожидаемым результатом и ветку `feat/краткое-название`, `fix/краткое-название` или `test/краткое-название`.
3. Внесите изменение и выполните подходящие проверки.
4. Создайте pull request, опишите изменения и приложите результаты проверок.
5. Попросите второго участника проверить изменение перед слиянием.

Подробности: [участие в разработке](CONTRIBUTING.md), [статическое тестирование](docs/quality.md).

## Проверки репозитория

GitHub Actions проверяет оформление файлов через Prettier, ошибки пробелов Git и Python-файлы через Ruff. ESLint и проверка типов TypeScript подключаются вместе с интерфейсом. Успешная проверка оформления не подтверждает работоспособность ещё не написанного приложения.

```sh
python -m pip install -r requirements-dev.txt
python -m ruff check .
python -m ruff format --check .
npx --yes prettier@3.6.2 --check .
```

Исходные интервью, личные данные, ключи и локальные базы в этот репозиторий не включаются.
