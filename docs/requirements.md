# Требования MVP

Источник: документ команды `Trebovaniya_K_stolu.docx` от октября 2026 года. Ниже — краткая текстовая версия для разработки, а не отчёт о готовности функций.

## Обязательные функции

| ID  | Результат                                                                                         |
| --- | ------------------------------------------------------------------------------------------------- |
| F1  | Каталог 10–15 рецептов: шаги, длительности, активность, оборудование, температура и зависимости   |
| F2  | Выбор 2–3 блюд с поиском по названию                                                              |
| F3  | Своё блюдо: название, общее и активное время, оборудование; подготовка → готовка → подача         |
| F4  | Профиль кухни: 1–6 конфорок, наличие духовки, число кастрюль и сковород; сохранение на устройстве |
| F5  | Сообщение о нехватке оборудования без самостоятельной смены способа приготовления                 |
| F6  | Общий план без пересечений активных шагов, перегрузки оборудования и нарушений зависимостей       |
| F7  | Обзор плана: примерное время подачи, длительность, шаги с названием/цветом блюда и началом        |
| F8  | Объяснение последовательного использования духовки при разных температурах                        |
| F9  | Экран «Сейчас»: текущий и следующий шаги, пассивные процессы                                      |
| F10 | Подписанные таймеры; по истечении требуется подтверждение, оборудование само не освобождается     |
| F11 | «Готово», «+2 мин», «+5 мин»; защита от повторного учёта нажатия                                  |
| F12 | Пересчёт будущего плана при сохранении начатых и завершённых шагов                                |
| F13 | Восстановление сессии и верных таймеров после перезагрузки                                        |

## Ограничения качества

- N1: ширина от 360 px без горизонтальной прокрутки.
- N2: текущий шаг шрифтом не меньше 28 px.
- N3: «Готово» занимает не меньше трети высоты экрана, остальные кнопки от 48 px.
- N4: в среднем не более одного касания на шаг.
- N5: план для трёх блюд по десять шагов рассчитывается не дольше двух секунд.
- N6: каждый план до показа проходит независимый валидатор.
- N7: контраст от 4,5:1, блюда различаются названием и цветом.
- N8: русский язык, браузер, без установки и регистрации.
- N9: время подачи примерное, готовность проверяет человек; сигнал на заблокированном устройстве не гарантируется.

Желательные функции: предотвращение сна экрана, список продуктов, итог готовки и обратная связь, повторное использование своего блюда, общая пауза. Они не должны задерживать обязательный MVP.
