# Анализ аналогов «К столу»

Сравнение из октябрьского отчёта, раздел 3.2. Сведения зафиксированы на **22 октября 2026 года** по официальным описаниям и документации. Возможности приложений на практике не проверяли.

| Решение                                                                         | Тип аналога | План нескольких блюд  | Учёт оборудования                                    | Особенности на дату сравнения                    |
| ------------------------------------------------------------------------------- | ----------- | --------------------- | ---------------------------------------------------- | ------------------------------------------------ |
| [Fatto](https://itsfatto.com/)                                                  | Прямой      | Общий план по шагам   | Да                                                   | Браузер и iOS. Бесплатный тариф до двух рецептов |
| [Pinch](https://pinch.cooking/)                                                 | Прямой      | Время начала блюд     | Выбор техники и режима. Ограничения требуют проверки | iPhone. Есть бесплатный режим                    |
| [Convivium](https://github.com/bell-kevin/convivium)                            | Прямой      | Общий план по шагам   | Да                                                   | Браузер, открытый код и примеры ужинов           |
| [CookSync](https://play.google.com/store/apps/details?id=com.nuvement.cooksync) | Прямой      | Общий план по шагам   | Да, включая занятость повара                         | Android, локальное хранение, без подписки        |
| [Food.ru](https://food.ru/about)                                                | Косвенный   | В описании не заявлен | В описании не заявлен                                | Русскоязычный каталог рецептов                   |

Fatto и CookSync заявляют пересчёт при задержках. Convivium учитывает занятость повара, конфорок и духовки. Команда «К столу» выбрала русскоязычный сценарий буднего ужина в браузере, подготовленный каталог и экран с одним текущим действием. Удобство этого сценария предстоит проверить в сравнительной готовке. [Отчёт об исследовании](research-report.md)
