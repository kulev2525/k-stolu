# Участие в разработке

## Авторство и история

Перед первым коммитом настройте `git config user.name` и `git config user.email`. Используйте подтверждённый адрес своего аккаунта GitHub или адрес `noreply` из его настроек.

Один коммит — одно законченное изменение. Примеры: `feat: validate kitchen equipment`, `test: cover overlapping active steps`, `fix: preserve running steps during recalculation`.

В описании pull request укажите задачу, написанный код и результаты проверок. Совместное авторство отмечайте только при реальной совместной работе. При слиянии сохраняйте авторство; merge commit позволяет сохранить отдельные коммиты участников.

## Порядок изменения

1. Возьмите небольшую задачу с понятным результатом и укажите ответственного в GitHub Issues.
2. Обновите локальную `main`, создайте отдельную ветку.
3. Напишите код и проверки по смыслу изменения.
4. Выполните статические проверки из README и тесты изменяемого компонента, когда они появятся.
5. Откройте pull request и получите ревью второго участника.
6. Исправьте замечания, дождитесь зелёных проверок и выполните слияние.

Для `main` включена защита GitHub: нужен pull request, одно одобрение другого участника, успешная проверка `static-checks` и закрытые обсуждения. Ветка должна быть обновлена относительно `main`; новые коммиты сбрасывают прежние одобрения. Правила действуют и для администратора. Принудительная перезапись и удаление `main` запрещены.

Слияние выполняется через merge commit, чтобы сохранить отдельные коммиты участников. После слияния рабочая ветка автоматически удаляется на GitHub.

## Предлагаемое разделение первых задач

- Максим: доменные модели и проверка оборудования.
- Арсений: выбор блюд и форма своего блюда.
- Андрей: независимый валидатор плана и тесты конфликтов.

## Перед публикацией

Проверьте состав `git diff --cached`. Не добавляйте интервью, персональные данные, `.env`, токены и локальные базы. Новые библиотеки добавляются с файлом фиксированных зависимостей соответствующего компонента. Лицензию распространения кода команда выбирает отдельно.
